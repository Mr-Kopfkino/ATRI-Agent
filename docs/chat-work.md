# 普通聊天中的工作任务

代码快照：2026 年 10 月 23 日；人格与知识资料及本文更新：2026 年 10 月 25 日。本文说明公开代码的交互与权限合同。公开目录现包含 `assets/derived/persona.json` 与 `assets/derived/knowledge.json`，仍不含运行美术与音频、完整原作剧本、模型、解释器、依赖安装包、凭据或用户状态，不能仅凭本目录直接启动完整应用。

## 对话流程

正常聊天回复包含双语 `segments`、记忆候选 `memories` 和可选 `work`。宿主把当前可执行范围与任务身份作为能力快照提供给模型，同一次模型回复完成语义判断和正常台词承接；普通聊天的 `work` 省略或为 `null`。用户只是讨论方法、询问能力、引用别人的指令或进行假设时，不应因此执行任务。

用户明确委托任务、且宿主校验允许时，先显示并按既有设置播放角色承接，再启动后台工作流。新任务默认使用 Pi 与用户自行配置的对话接口；明确选择其他执行器时仍须通过其就绪和权限检查。能力不足或任务指代不明确时，应先诚实说明或澄清。

支持的请求类型如下：

| `intent` | 行为 |
| --- | --- |
| `create` | 新建专用工作区、任务及执行尝试 |
| `continue` | 在已有任务和工作区上继续用户本次修订 |
| `retry` | 按用户明确要求重试已有任务 |
| `report` | 只读取已有任务的真实状态及结果 |
| `cancel` | 请求停止明确指定的已有任务 |

请求还包含 `workId`、完整执行指令 `instruction`、执行器 `provider`、简述 `summary` 及可选完整网址 `browserUrl`。现有任务身份必须来自宿主快照；模型不能自行创建权限字段、猜测任务 ID，或因询问进度而重新执行。

任务处理期间，输入框显示“亚托莉正在工作”，暂停发送、录音和图片输入；独立区域显示实际状态、工具步骤和有界输出。结束、失败或取消后，通过正常双语台词及日语语音汇报真实情况。结果汇报轮强制要求 `work` 为 `null`，不能递归调度第二个任务。汇报接口不可用时使用双语兜底；语音异常时保留完整文字，原有关闭语音设置继续生效。

## 权限与外置人格

聊天明确委托的新任务使用专用受管工作区；继续及重试保留原任务与已登记工作区。Pi 的自动文件写入仅限相应工作区，仍接受路径、链接／联接、Git 内部、凭据文件、工具名称和文件大小检查，并写入权限账本。

原 WORK 面板继续提供新建、执行、继续、重试、中止、验收及产物预览等入口。面板任务仍按原逻辑批准启动和逐次工具写入；聊天自动写入的授权不改变面板流程。

Pi 的文件工具范围为 `read`、`ls`、`write`、`edit`，不提供任意 shell、全盘访问或任意联网搜索。用户明确提供完整 HTTP(S) 网址后，受管浏览器仍需确认外部访问，仅允许批准 origin 内的 GET／HEAD；不开放登录、点击、表单提交或下载。可选 Codex CLI 使用自身已登记的工作区沙箱合同，其工具与登录不随此源码包提供。

角色口吻由随包的 `assets/derived/persona.json` 外置资料决定，`knowledge.json` 提供角色知识、来源和短句示例；两份文件按字节保留原项目内容。公开副本的 C# 系统规则仍为通用的虚构角色规则，运行时另行读取人格资料。文字成果沿用登记口吻；技术代码、结构化数据、引用及用户要求的精确格式优先。人格资料不能扩大权限、虚构用户关系或证明任务已经执行。原作角色与引用内容的独立权利说明见 [第三方来源说明](../THIRD_PARTY_NOTICES.md)。

## 生命周期与记忆

宿主轮次持有承接、执行、产物收尾和汇报。稳定请求标识用于回执恢复和避免重复创建；后续状态必须匹配具体任务与执行尝试。切换会话、恢复记忆、恢复出厂及退出会排空当前工作流，旧事件不能写回新会话。

任务中止后，只有确认相应执行已停止才恢复聊天输入；无法确认时提示检查任务或重新启动应用。任务已经结束时，中止只停止汇报等待或语音，不把成功状态改为取消。进程重启留下的未完成尝试标记为中断，不自动重跑；成功状态须在产物登记收尾之后提交。

聊天记忆只保存明确标注为概括的用户指令简述、宿主真实状态及产物数量。原始工单、工具过程、执行器原文与完整口头汇报不进入聊天 `messages`、事实、历史索引、摘要或模型整理。独立 Work 账本继续保留任务恢复所需的详情；执行指令和工具读取内容仍可能发送至用户自行配置的模型服务。

## 代码与验证边界

| 文件 | 职责 |
| --- | --- |
| `src/Atri.Core/ChatWork.cs`、`ProtocolClient.cs` | 可选请求、严格字段校验、报告轮禁止新任务 |
| `src/Atri.Core/ChatWorkSession.cs` | 身份、幂等请求、回执恢复、取消及停止确认 |
| `src/Atri.Desktop/ChatWorkView.cs` | 输入锁、进度、正常语音承接与汇报 |
| `src/Atri.Core/ChatWorkMemory.cs` | 简述与宿主状态的受限记忆入口 |
| `runtime/capabilities/bridge.py`、`pi_provider.py` | 复用独立任务账本、权限与产物登记 |
| `runtime/capabilities/verify_chat_work.py` | 真实账本及合成 Pi 通信的隔离后端合同检查 |

后端合同检查不请求外部模型，也不代表真实 Pi 模型效果；所需外置人格现已随包提供，源产品的其他运行资源与验证前提仍需另行补齐。独立 C# 测试工程、历史运行报告及验收截图均未随包提供。公开源码的静态检查或编译通过，只支持相应检查范围。

真实模型的任务路由质量、供应商 SSE／工具调用支持、翻译与人格表现、人工听感、不同硬件和多日稳定性需要分别验证。此入口没有新增完整 MCP／Skills、任意联网搜索、桌面控制或上游完整规划器。
